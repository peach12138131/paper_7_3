## 1. 方法与通用公式

### 1.1 分析单元
- 每个 **图 × 菌株组合 × 菌种** 为一个独立分析单元（如 fig 2 / D1-L43 / Lm）。
- 因素：时间（biofilm 4 个水平：6、24、48、72 h；planktonic 5 个水平：0、6、24、48、72 h —— 本次文件中仅有 biofilm 数据）。
- 因变量：log₁₀ CFU（直接使用表中数值，未做任何变换）。
- 每个时间点 n = 6 个重复；显著性水平 α = 0.05。
- 记号：k = 时间水平数，nᵢ = 第 i 组样本数，N = Σnᵢ，xᵢⱼ = 第 i 组第 j 个观测值，x̄ᵢ = 组均值，x̄ = 总均值。

### 1.2 前提检验

**(1) 正态性：Shapiro–Wilk 检验**

$$W=\frac{\left(\sum_{j=1}^{n} a_j\,x_{(j)}\right)^2}{\sum_{j=1}^{n}(x_j-\bar x)^2}$$

- 含义：x₍ⱼ₎ 为排序后的第 j 个值，aⱼ 为由正态顺序统计量期望与协方差矩阵导出的系数。W 越接近 1 越符合正态；H₀：数据来自正态总体，p < 0.05 拒绝正态。
- 每组只有 6 个值，单组检验效能很低，因此以 **ANOVA 残差** eᵢⱼ = xᵢⱼ − x̄ᵢ（合并 N 个）的 Shapiro–Wilk 结果为主判据，各组结果作参考。

**(2) 方差齐性：Brown–Forsythe（以中位数为中心的 Levene）检验**

$$z_{ij}=|x_{ij}-\tilde x_i|,\qquad
W_L=\frac{(N-k)\sum_i n_i(\bar z_{i\cdot}-\bar z_{\cdot\cdot})^2}{(k-1)\sum_i\sum_j(z_{ij}-\bar z_{i\cdot})^2}\sim F(k-1,\,N-k)$$

- 含义：x̃ᵢ 为第 i 组中位数；本质是对"离中位数的绝对偏差"做单因素 ANOVA。H₀：各组方差相等，p < 0.05 认为方差不齐。

**(3) 方法选择规则**

| 情形 | 采用方法 |
|---|---|
| 残差 SW p ≥ 0.05 且 Levene p ≥ 0.05 | 单因素 ANOVA + Tukey HSD |
| 一项 0.01 ≤ p < 0.05、另一项 ≥ 0.05（近似满足） | 单因素 ANOVA + Tukey HSD（报告中注明） |
| 某组 6 个值完全相同（方差 = 0），或任一 p < 0.01，或两项均 < 0.05 | Kruskal–Wallis + Dunn（Holm 校正） |

### 1.3 单因素 ANOVA

$$SS_B=\sum_{i=1}^{k} n_i(\bar x_i-\bar x)^2,\quad
SS_W=\sum_{i=1}^{k}\sum_{j=1}^{n_i}(x_{ij}-\bar x_i)^2,\quad
SS_T=SS_B+SS_W$$

$$df_B=k-1,\quad df_W=N-k,\quad MS_B=\frac{SS_B}{df_B},\quad MS_W=\frac{SS_W}{df_W},\quad
F=\frac{MS_B}{MS_W}\sim F(df_B,df_W)$$

- 含义：SS_B 为组间（时间引起的）变异，SS_W 为组内（重复间随机误差）变异；F 越大说明时间效应相对误差越强。p = P(F(df_B, df_W) ≥ F)。
- 效应量 η² = SS_B / SS_T：时间解释的总变异比例。

### 1.4 Tukey HSD 事后多重比较

$$SE_{ij}=\sqrt{\frac{MS_W}{2}\left(\frac1{n_i}+\frac1{n_j}\right)},\qquad
q_{ij}=\frac{|\bar x_i-\bar x_j|}{SE_{ij}},\qquad
p_{ij}=P\big(Q_{k,\,df_W}\ge q_{ij}\big)$$

- 含义：Q 为学生化极差分布（参数 k、df_W），它本身已控制全部成对比较的族错误率，故无需另行校正。
- 等价判据：|x̄ᵢ − x̄ⱼ| > HSD = q₀.₀₅(k, df_W) × SE 即显著。

### 1.5 Kruskal–Wallis 检验

将 N 个值统一从小到大编秩（相同值取平均秩），Rᵢ 为第 i 组秩和，R̄ᵢ = Rᵢ/nᵢ。

$$H=\frac{12}{N(N+1)}\sum_{i=1}^{k}\frac{R_i^2}{n_i}-3(N+1)$$

$$C=1-\frac{\sum_g (t_g^3-t_g)}{N^3-N},\qquad H^*=\frac{H}{C}\sim\chi^2(k-1)$$

- 含义：H 衡量各组平均秩偏离总体平均秩 (N+1)/2 的程度；t_g 为第 g 个结（相同值）的个数，C 为结校正系数。p = P(χ²(k−1) ≥ H*)。
- 效应量 ε² = (H* − k + 1)/(N − k)。

### 1.6 Dunn 检验（Holm 校正）

$$SE_{ij}=\sqrt{\left[\frac{N(N+1)}{12}-\frac{\sum_g(t_g^3-t_g)}{12(N-1)}\right]\left(\frac1{n_i}+\frac1{n_j}\right)},\qquad
z_{ij}=\frac{\bar R_i-\bar R_j}{SE_{ij}},\qquad p_{ij}=2\,[1-\Phi(|z_{ij}|)]$$

**Holm 逐步校正**：共 m = k(k−1)/2 个比较，将原始 p 从小到大排序 p₍₁₎ ≤ … ≤ p₍ₘ₎，

$$p^{adj}_{(i)}=\max_{l\le i}\Big\{\min\big[1,\,(m-l+1)\,p_{(l)}\big]\Big\}$$

p^adj < 0.05 判为显著。Holm 控制族错误率，且比 Bonferroni（p × m）更有检验效能。

### 1.7 字母标记法
- 各时间点按均值**从低到高**排序，最低者先得字母 a。
- 采用 insert-and-absorb 算法（Piepho, 2004）：对每一对显著差异的时间点，将同时含有二者的字母列拆分，然后删去被其它列包含的冗余列。
- **共享同一字母的时间点之间无显著差异**；没有共同字母的则差异显著。
- 若总体检验（ANOVA F 或 KW H）不显著，则所有时间点均标 a。

> 说明：下文代入过程中的中间值显示到 4 位小数，最终统计量由程序以全精度计算，因此手算末位可能存在舍入误差。
> 程序已自动核对：手算 F、p 与 `scipy.stats.f_oneway` 一致；手算 H*、p 与 `scipy.stats.kruskal` 一致；Tukey p 与 `scipy.stats.tukey_hsd` 一致；字母与成对比较结果一致。
